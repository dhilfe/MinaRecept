# Integritetspolicy (Privacy Policy)

Senast uppdaterad: 2025-12-28

## Vilka data vi samlar in
- Konto: e-postadress, lösenord (hashat), användargenererat innehåll (recept, inköpslistor, bilder)
- Metadata: användarens valda inställningar, sessionsdata

## Hur data används
- För att möjliggöra inloggning och synkronisering mellan app och webb
- För att spara och visa dina recept, veckomenyer och inköpslistor
- För att förbättra tjänsten (anonym statistik)

## Delning av data
- Vi delar inte din data med tredje part, förutom om det krävs enligt lag

## Radering av data
- Du kan begära radering av ditt konto och all data genom att kontakta support@receptapp.se

## Kontakt
support@receptapp.se
