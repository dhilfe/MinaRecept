# FR-20251227-01: Root README.md

## Bakgrund
Repo:t saknar en README i root. Det gör det svårt att snabbt förstå:
- vad projektet innehåller (Django + iOS + Share Extension)
- hur man startar backend lokalt
- hur man bygger iOS-appen
- hur man kör tester

## Mål
Skapa en tydlig, kort och praktisk `README.md` i repo-roten med:
- översikt av mappar
- snabbstart för backend
- testkommandon
- iOS build-instruktioner (XcodeGen + xcodebuild)
- pekare till befintlig dokumentation i `docs/`

## Omfattning
- Endast dokumentation: ingen funktionell kodförändring krävs.
- Inga hemligheter/API-nycklar i README.

## Acceptanskriterier
- Det finns en `README.md` i repo-roten.
- Instruktionerna fungerar för en ny utvecklare på macOS.
- README länkar vidare till `docs/API.md`, `docs/specification.md` och `docs/TODO.md`.
